📌 Project Title
Event Registration Website

🧠 Project Description
This is a simple event management and registration website built using HTML, CSS, and JavaScript.  
It allows users to view event details and register online easily with a clean and responsive UI.

✨ Features
- Event information display (Date, Venue, Highlights)
- Responsive card-based UI
- Registration form with validation
- Clean and modern design
- Success confirmation page

🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (basic validation)
